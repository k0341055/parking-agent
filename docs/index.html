運作方式

  • 檢查：GitHub Actions 每次跑約 5 分鐘，每 15～25 秒查一次名額。排程要靠 cron-job.org 每 5 分鐘觸發才準時（設定方式見 README）。
  • 午夜開放：網站每天 00:00 開放「20 天後」的日期。目標日期當晚開放時，監控會撐過午夜並改成每 3 秒查一次。
  • 自動預約：有名額就同時通知並送出，再用查詢記錄確認。網站若要求 reCAPTCHA 人工驗證，程式會停下來通知你手動完成，不會去破解驗證。
  • 同一台車：網站規定重新申請前要先取消舊登記。程式不會幫你取消，遇到時會在通知附上取消連結。
  • 公開與隱私：這個頁面和 repo 都是公開的，任何人都看得到進場日、天數和代稱（Booking_N、Recipient_N），但看不到姓名、車牌和收件資料。沒有 token 只能看、不能改。
  • 裝置副本：姓名和車牌會留一份在這台裝置的瀏覽器，「一鍵填單」書籤也含這些資料。別在共用電腦上使用。
